## Current status

This repository contains the working MVP foundation and deterministic simulator demo for the HackTX prototype. It currently demonstrates:

- 12-region guided synthetic capture and replay
- Explicit covered, partial, blocked, and unseen states
- Evidence-backed synthetic Vision findings
- Uncertainty-aware presentation and human-review escalation
- Contract, Swift package, QA fixture, and iOS Simulator validation

The next product increments are live camera/ARKit capture, a polished surface-anchored 3D vehicle asset, and synthetic customer/vehicle/loan/lease data driving the final financial recommendation. The current replay path is intentionally labeled synthetic and is the reliable demo path.
