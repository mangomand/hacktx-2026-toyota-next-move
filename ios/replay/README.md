# Deterministic iOS replay

`replay-scan-session.json` is generated from `CaptureReplay.sessionJSON()` with fixed replay ID `replay-20261024` and fixed UTC timestamp `2026-10-24T00:00:00Z`. Artifact references are repository-relative and point to the sibling `frame-*.json` evidence files. This fixture intentionally contains covered, partial, and unseen regions; `unknownRegions` includes every partial, unseen, or blocked region, and no unseen region implies a clean inspection.
